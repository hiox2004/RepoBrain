# RepoBrain VS Code & Cursor Extension

Autonomous Codebase Memory Engine, Static Blast Radius, and LangGraph Multi-Agent Swarm for VS Code, Cursor, and Windsurf.

---

## ✨ Features

* **⚡ Live Blast Radius CodeLens:** Attaches clickable call graph insights directly above functions and classes. See callers and dependent test suites before making code edits.
* **🔧 Autonomous CI Test Self-Healing (`repobrain.healTest`):** 1-click test failure diagnosis, blast radius checking, and bounded $\le 3$-iteration repair with non-destructive surgical rollback.
* **🐝 LangGraph Multi-Agent Swarm (`repobrain.swarmTask`):** Dispatch autonomous teams (Architect $\to$ Coder $\to$ Tester $\to$ Supervisor) with RepoBrain AST memory as the shared blackboard.
* **🔍 Two-Stage Hybrid Search (RRF $k=60$):** Sub-symbol code retrieval combining split-token lexical search and dense cross-encoder reranking.
* **🌐 Status Bar & Interactive Workbench:** Direct link to RepoBrain's local React engineering workbench and 15-module interactive CTO academy.

---

## 🚀 Getting Started

1. Ensure Python 3.10+ is installed with `repobrain` dependencies (`pip install -e .`).
2. Open the Command Palette (`Ctrl+Shift+P` / `Cmd+Shift+P`):
   - `RepoBrain: Open Developer Workbench`
   - `RepoBrain: Heal Failing Test Suite`
   - `RepoBrain: Launch Autonomous Multi-Agent Swarm`
   - `RepoBrain: Compute Static Blast Radius of Symbol`
3. Hover over any function or class in `.py` or `.ts` to view the **⚡ Blast Radius** CodeLens.
